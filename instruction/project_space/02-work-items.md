# 主 Tab：工作项

“工作项”是团队记录和执行具体事项的集合页。当前只有一个二级 Tab：

1. 工作项

页面在这个二级 Tab 内提供任务模板筛选、保存视图、六种展示模式、批量操作、导出和新建事项。

## 1. 页面从哪里得到内容

工作项集合同时受以下条件约束：

- 当前用户能够进入“工作项”主 Tab。
- 任务模板处于可查看且配置就绪状态。
- 当前用户对具体事项拥有 `view`。
- 保存视图、字段投影和查询结果会在服务端重新鉴权。
- disabled、archived 空间只读。

分享一个视图只分享查询和展示配置，不会扩大接收者对工作项或字段的权限。

## 2. 顶部控件顺序

### 2.1 保存视图目录

第一个下拉框显示：

- 个人视图
- 共享视图

选择保存视图后，系统按视图保存的查询定义重新取数，并重新校准事项和字段权限。清除选择后恢复当前默认定义。

### 2.2 任务模板筛选

第二个下拉框显示当前用户可查看并且配置就绪的任务模板。

当前界面的空选项文案是“全部类型”，但清除后会立即回退到第一个可见模板，实际查询始终带一个 `typeId`。因此当前版本还不能在一次查询中查看所有模板，这是已知边界。

### 2.3 展示模式

顺序固定为：

1. 表格
2. 紧凑列表
3. 层级树
4. 看板
5. 日历
6. 甘特

### 2.4 模式专属参数

看板：

- 不使用泳道
- 按我的参与角色分泳道

日历：

- 开始日期字段 key
- 可选结束日期字段 key
- 月、周、日粒度
- IANA 时区
- 锚点日期
- 上一段、下一段

甘特：

- 开始日期字段 key
- 可选结束日期字段 key
- 日、周、月缩放
- IANA 时区
- 锚点日期

### 2.5 通用展示参数

- 列表密度：舒适、紧凑。
- 显示列：编号、标题、状态、更新于、创建于、流程状态、我的角色。
- 保存偏好。
- 编辑当前保存视图，或另存为新视图。

默认使用表格，默认列是编号、标题、状态、更新于，按更新时间倒序，单次最多读取 50 条。

当前边界：

- 自定义字段还不能加入集合页列选择。
- 当前没有标题搜索、状态筛选、通用筛选器或排序编辑器。
- 接口返回下一页游标，但页面没有翻页或加载更多，超过 50 条不会继续展示。
- 类型、保存视图和偏好加载失败时没有各自独立的错误提示。
- “保存偏好”在看板、日历、甘特下保存该模式的配置，但不一定保存“当前正在使用该模式”。
- “另存为视图”只保存表格、列表或层级树展示定义，不能保留看板、日历或甘特模式。

## 3. 保存视图

### 3.1 当前视图提示区

选中一个保存视图后，页面显示：

- 视图名称
- “可管理”或“仅可使用”
- 重新校准权限的说明

可执行动作：

- 收藏
- 复制
- 分享与移交，仅可管理者可用
- 删除，仅可管理者可用并需要确认

### 3.2 新建或编辑视图

填写：

- 视图名称，必填
- 说明

保存的是查询定义和展示配置，不复制工作项数据。新建视图固定先创建为个人视图。

### 3.3 分享、撤销与移交

从空间有效成员中选择目标用户，并赋予：

| 权限 | 含义 |
| --- | --- |
| 仅使用 | 可以运行视图，不能修改或再次分享 |
| 可管理 | 可以编辑、分享和删除视图 |

支持的动作：

- 分享或更新权限
- 撤销分享
- 移交所有权，需要确认

当前分享列表显示的是用户 UUID 和权限，而不是成员显示名，选择时需要额外核对目标身份。

## 4. 批量操作与导出

集合页提供：

- 批量归档
- 批量恢复
- 导出 CSV
- 已选择数量

表格和层级树可以选择事项。导出使用当前查询和当前列，并在服务端重新鉴权。

当前边界：

- 表格复选框只粗略检查事项是否存在可用动作，没有分别核对 `archive` 或 `restore`。
- 归档和恢复按钮会同时出现，不会按所选事项的生命周期分别禁用。
- 批量结果只显示成功数和失败数，不展开单项失败原因。
- 紧凑列表、看板、日历、甘特没有复选框；从其他模式留下的选择可能继续保留。

执行前应确认所选事项状态和权限，失败后再逐条打开事项检查。

## 5. 六种展示模式

### 5.1 表格

功能：

- 按所选列展示。
- 支持横向滚动和多选。
- 点击整行或聚焦后按 Enter 打开详情。
- 标签、日期时间按列格式呈现。
- 空值显示“—”。

空状态显示“当前类型还没有工作项”；有创建权限时可以“创建第一条工作项”。加载失败时可重试。

### 5.2 紧凑列表

每条显示标题、编号和其他可见列组成的摘要。点击或按 Enter 打开详情。当前模式没有事项复选框。

### 5.3 层级树

层级树依赖已发布的 `parent_child` 关系定义。

顶部显示：

- 可见节点数
- 查询匹配数
- 最大可见深度
- 是否被预算截断

可以：

- 展开、折叠和懒加载子节点。
- 勾选事项用于批量操作。
- 点击节点进入详情。
- 查看为匹配事项补出的“路径上下文”祖先节点。

无结果时显示“当前查询没有可见层级节点”。加载失败时不会回退读取私有表或猜测隐藏路径。

### 5.4 看板

默认按状态分列：

- 普通模板：待处理、处理中、已完成、已取消。
- bug 模板：待处理、处理中、待验证、已关闭、已取消。

看板显示可见卡片数、候选评估数、预算截断状态，以及每列的可见数和 WIP 上限。

操作：

- 修改 WIP 上限并通过保存偏好持久化。
- 按参与角色分泳道。
- 拖放卡片。
- 键盘上下移动同列排序，左右触发跨列流程动作。
- 点击卡片进入详情。

目标列达到 WIP 上限时，前端会阻止移动；真正的流程动作仍由服务端重新鉴权。

### 5.5 日历

日历根据所选开始/结束字段投影工作项日程。

支持：

- 月、周、日窗口和时区。
- 查看可见日程数和日期窗口。
- 拖动全天事项或用左右方向键移动日期。
- 有结束字段时调整结束日期。
- 在“未安排日期”区为事项指定日期。
- 点击事项进入详情。

非全天时间点当前不能通过 Web 拖放处理，需要在日期时间字段中编辑。加载失败时不会回退读取私有投影。

### 5.6 甘特

顶部显示：

- 可见排期数
- 依赖线数
- 关键路径是否可用及降级原因
- 是否被预算截断

#### 排期基线

可以输入名称创建基线、选择已有基线、比较当前排期和删除基线。比较结果包括：

- 事项变化
- 新增依赖
- 移除依赖
- 是否截断

基线冻结事项 identity、日期、父级和依赖版本，保留 90 天；标题和权限仍按每次请求重新校准。当前删除基线没有二次确认。

#### 时间线和甘特主体

- 最小时间线只显示当前受权事项的排期事件。
- 事项按层级缩进，可以展开或折叠。
- 点击事项进入详情。
- 左右方向键移动一天。
- 有结束字段时可以调整结束日期。
- 无日期的事项显示“未安排日期”。
- 关键事项使用关键路径样式。
- 只显示两端都可见的依赖线。

甘特、最小时间线和依赖区分别有自己的失败或空状态。

## 6. 新建工作项

新建入口出现的条件：

- 空间为 active。
- 至少有一个配置就绪且当前用户拥有 `create` 的任务模板。

操作顺序：

1. 点击“新建工作项”。
2. 选择当前可创建模板；没有明确选择时回退到第一个可创建模板。
3. 系统加载该模板已发布版本的 create 布局、字段定义和字段访问投影。
4. 填写标题和运行时表单。
5. 点击“创建”，或在标题中按 Enter。
6. 创建成功后进入事项详情。

标题必填，最多 500 字。离线、表单未就绪、没有 `create` 或标题为空时不能提交。

### 6.1 字段控件

运行时可根据模型渲染：

- 单行文本、富文本
- 数字
- 布尔
- 单选、多选
- 日期、日期时间
- URL
- 用户
- 附件
- 工作项引用

字段访问投影决定：

| 模式 | 页面表现 |
| --- | --- |
| `hidden` | 完全不显示 |
| `read` | 显示但不可编辑 |
| `write` | 可以编辑 |
| `required` | 在可写基础上显示必填 |

### 6.2 配置异常时怎样处理

- 没有选择类型：先选择任务模板。
- 配置未发布或快照版本不支持：显示“该类型尚未发布可用配置”。
- 管理员可使用“去配置”；普通成员应联系空间管理员。
- 表单加载失败：窗口保留，可重试。
- 创建失败：输入保留，不会伪造成功。

### 6.3 当前运行时边界

- 用户字段尚未接入成员、部门、用户组候选目录。
- 附件字段在表单中仍是禁用占位；实际文件在详情的“协作记录 → 附件”上传。
- 工作项引用字段仍是禁用占位。
- 布局中的显示条件已经能配置，但当前运行时渲染器还没有执行条件表达式。
- `summary` 节点只显示占位说明。
- `relation` 节点只显示静态关系说明；真正建立关系要到“事项关系”。

## 7. 推荐使用顺序

1. 先选择任务模板，避免误以为当前页面能跨全部类型搜索。
2. 选择合适的展示模式和日期字段。
3. 需要反复使用的查询保存为个人视图。
4. 需要协作时再分享视图，并指定“仅使用”或“可管理”。
5. 新建事项后进入详情，继续完成状态、关系和协作操作。
