# 设置 → 工作模型

“工作模型”定义空间里有哪些任务模板、每种事项保存哪些数据，以及新建页和详情页怎样呈现。

推荐顺序：

1. 创建或选择任务模板。
2. 配置字段。
3. 配置新建页和详情页布局。
4. 配置字段访问。
5. 用访问预览校验不同身份。
6. 返回“流程与权限”完成流程、权限、校验和发布。

页面中的“任务模板”和代码/部分旧文案中的“工作项类型”是同一个对象。每个任务模板都有独立的字段、布局、流程、关系、权限和发布版本。

## 1. 任务模板目录

工作模型直接展示“工作项类型”目录，不再先打开一个重复的任务模板弹窗。

### 1.1 目录工具

- 类型状态筛选位于类型列表上方，文案为“全”“使用中”“已停”“已退”。
- 新建类型。
- 类型列表；每行以单行紧凑方式展示名称、永久 `typeKey` 和状态圆点，不再显示类型图标。
- 通过列表行末的拖拽手柄调整当前配置顺序，不再提供上移、下移箭头；手柄获得焦点后也可使用上、下方向键排序。

### 1.2 选中模板后的详情

显示：

- 显示名称
- 系统类型或自定义类型
- 类型说明
- 排序值
- 聚合版本
- 当前发布版本
- 更新时间
- 当前配置哈希

状态和永久 `typeKey` 已在类型列表中展示，详情标题不再重复显示。

这些版本与哈希用于判断当前看到的是哪份定义，不是成员手工填写的业务字段。

### 1.3 可用操作

服务端按模板状态和能力决定是否显示：

- 配置字段
- 页面布局
- 编辑
- 复制
- 恢复
- 停用
- 退役

“配置字段”和“页面布局”是当前选中模板的子页面；“发布”不在这里，统一到“设置 → 流程与权限”。

### 1.4 新建、编辑和复制

字段：

| 字段 | 作用 |
| --- | --- |
| 类型标识 | 模板内永久 key；创建后不可修改；以小写字母开头，只允许小写字母、数字、下划线 |
| 显示名称 | 面向使用者显示 |
| 图标标识 | 目录和入口的视觉标识 |
| 类型说明 | 解释这类事项的用途和边界 |
| 排序值 | 决定目录顺序 |

复制会创建一份独立模板，不会让两者以后自动同步。

### 1.5 生命周期

- 停用：可以恢复；成员执行入口不再显示该模板。
- 恢复：重新参与配置和成员入口判断。
- 退役：不可恢复，不再参与后续配置。

系统预置模板可以调整顺序、复制、停用，但不能修改永久标识和系统展示定义，也不能退役。这是为了保护平台基线。

## 2. 配置字段

字段决定一条工作项可以保存哪些业务数据。仅创建字段还不会自动把它显示在表单中，之后必须把字段放入 create/detail 页面布局。

### 2.1 页面工具

- 返回类型
- 字段列表上方先显示状态筛选，文案为“全”“使用中”“已停”“已退”
- 状态筛选下方按字段名称或字段 key 搜索
- 字段列表每行以单行紧凑方式展示“名称、字段 key、状态圆点、字段类型”，不再显示字段图标
- 新建字段
- 字段类型筛选
- 排序：配置顺序、名称、最近更新
- 字段顺序通过列表行末的拖拽手柄调整，不再提供上移、下移箭头；只有选择“配置顺序”、搜索为空且字段类型为“全部类型”时才可调整
- 拖拽手柄获得焦点后，也可使用上、下方向键排序

### 2.2 支持的字段类型

| 类型 | 适用内容 |
| --- | --- |
| `text` | 短文本或富文本业务说明 |
| `number` | 数量、金额、分数等数值 |
| `boolean` | 是/否开关 |
| `single_select` | 从固定选项中单选 |
| `multi_select` | 从固定选项中多选 |
| `user` | 成员、部门或用户组引用 |
| `date` | 不带时间的日期 |
| `datetime` | 带时间和时区语义的时间点 |
| `url` | 受限 Web 地址 |
| `attachment` | 文件引用 |
| `work_item_reference` | 另一工作项的引用 |

### 2.3 新建字段

填写：

- 字段类型
- 永久字段 key，模板内唯一且创建后不可修改
- 显示名称
- 字段说明

创建时使用字段类型目录的默认配置。随后应进入“配置”补充默认值、选项、校验和类型专属规则。

### 2.4 字段详情与生命周期

详情显示：

- 系统字段/自定义字段
- 字段类型与存储语义
- 排序、聚合版本、更新时间、配置哈希
- 默认值
- 校验规则数
- 选项数
- 支持的操作符

状态和永久字段 key 已在字段列表中展示，字段详情不再重复显示。

操作包括配置、编辑名称与说明、停用、恢复和退役。系统字段可以排序和进行允许的生命周期操作，但不能修改定义或类型配置。

停用字段不能继续被有效发布布局引用；退役前应先检查页面布局、权限、流程必填字段和现有版本依赖。

## 3. 字段配置抽屉

### 3.1 基础配置

- 必填或可选。
- 默认值。

`user`、`attachment`、`work_item_reference` 不能在这里设置对象型默认值。

这里的“必填”是字段基础配置；最终运行时还会结合页面字段权限和流程动作的 required fields 判断。

### 3.2 单选和多选选项

每个选项包含：

- 永久选项 key
- 显示名称
- 颜色
- 状态：使用中/已停用
- 顺序

支持添加、上移和下移，最多 200 个。已经保存的选项 key 不可修改或直接删除；不再使用时应停用，以便历史数据仍能解释。

### 3.3 结构化校验规则

规则不接受脚本、SQL 或任意表达式。支持：

- 长度范围
- 数值范围
- 数值精度和小数位
- 正则格式
- 预置格式：email、hostname、ipv4、uuid
- 允许值

前端单字段最多配置 20 条，服务端发布时还会再次校验。

### 3.4 用户字段

可配置：

- 允许主体：成员、部门、用户组。
- 选择范围：每行 `member:UUID`、`department:UUID` 或 `user_group:UUID`。
- 最多选择数。

当前工作项运行表单尚未接入成员、部门、用户组候选目录，所以字段模型可以保存，但成员侧控件可能没有可选项。

### 3.5 日期字段

- 相对默认值：none、today。
- 最早值、最晚值。

### 3.6 日期时间字段

- 展示时区。
- 精度：minute、second、millisecond。
- 相对默认值：none、now。
- 最早值、最晚值。

服务端统一按 UTC 存储，展示时区只决定输入和呈现语义。

### 3.7 URL 字段

- 是否允许 HTTPS。
- 是否允许 HTTP。
- 最大长度。

始终禁止 URL 用户名、密码、危险协议、控制字符和反斜线。敏感凭据不应放入普通 URL 字段。

### 3.8 附件字段

- 最多文件数。
- MIME 类型白名单。
- 单文件最大字节数。

当前新建/详情表单中的附件字段仍是占位控件；实际文件上传在“工作项详情 → 协作记录 → 附件”。

### 3.9 工作项引用字段

- 允许引用的任务模板。
- 最多引用数。
- 固定为 outbound。

字段引用只保存字段值意义上的引用；规范的父子、依赖、阻塞和可治理关系应在“流程与权限 → 关系定义”中建模，并在事项详情的“事项关系”中建立。

## 4. 页面布局

页面顶部先选择：

- 新建页
- 详情页
- 刷新

新建页决定创建事项时的表单；详情页决定创建成功后打开事项的主体表单。

内部子 Tab 顺序：

1. 表单与页面
2. 字段权限
3. 访问预览

从工作模型进入时不再显示重复的“发布配置”子 Tab；发布统一在“流程与权限”。

## 5. 表单与页面

没有布局时，可以“使用当前字段初始化”。这会把当前字段生成一份起步结构，之后仍要人工分区、排序和检查权限。

### 5.1 控件区

可以添加：

- 区块 `section`
- 标签页 `tab`
- 分栏 `column`
- 关系控件 `relation`
- 摘要 `summary`
- 当前模板字段

同一个字段不能在同一布局中重复添加。

### 5.2 布局结构

- 用树表示节点层级。
- 支持同层拖动排序。
- 支持上移、下移。
- `Alt+↑/↓` 移动选中节点。
- `Delete` 删除选中节点。
- 删除父节点会删除整个子树和其中字段引用。
- 包含字段的子树不能复制。

建议先建立 section/tab/column 骨架，再把字段放入；删除前检查子树，避免误删整组字段引用。

### 5.3 节点属性

通用属性：

- 节点类型，只读。
- 永久节点 key，只读。
- 显示名称。

关系节点还包括：

- 永久 relation key。
- 展示模式：picker、list、hierarchy、impact。
- 展示硬限：1–200。

新建页中的关系控件只能使用 `picker`。当前成员运行时的 relation 节点还只是静态说明，真正关系操作仍在事项详情中完成。

### 5.4 显示条件

可以添加字段条件，选择“全部满足”或“任一满足”，并可对最终结果取反。操作符来自字段类型目录，比较值由管理员填写。

当前编辑器只编辑字段条件。已有上下文表达式不能编辑但会保留；只有“清除条件”会移除。更重要的是，当前工作项运行时渲染器尚未实际执行这些条件表达式，所以不能把它当成已经生效的动态表单能力。

## 6. 字段权限

此页决定字段进入布局后，在不同身份下是：

- `write`：可写。
- `read`：只读。
- `hidden`：隐藏。

可以配置默认模式、默认必填，以及 owner、admin、member、guest、non_member、enterprise_admin 的角色覆盖。覆盖可以继承默认值；只有 `write` 才能设为必填。

冲突优先级：

```text
hidden > read > write
```

### 6.1 与数据权限策略的区别

| 层次 | 回答的问题 |
| --- | --- |
| 数据权限策略 | 这个主体能否查看或操作这条事项/这个动作 |
| 字段权限 | 已经进入页面后，这个字段隐藏、只读还是可写 |

字段权限不能反向突破事项数据权限。即使字段标为 write，如果当前用户没有事项 `edit`，也不能写入。

当前面板只编辑默认效果和角色覆盖；已有条件规则会保留，但不能在这里修改。

## 7. 访问预览

访问预览通过服务端投影模拟指定身份看到的页面。

输入：

- 预览角色。
- 空间状态：active、disabled、archived。
- 模板状态：active、disabled、retired。
- 选中字段状态：active、disabled、retired。
- 字段样本 JSON。

输出：

- 当前身份的页面投影或合成预览。
- 安全诊断。
- 不可见样本字段提示。
- 最终表单渲染。

预览只使用已经保存到服务端的策略。字段权限有未保存修改时，必须先保存再运行。

访问预览适合检查字段投影，不等于完整用户模拟；主导航、事项级策略、流程守卫等还要用实际测试账号或事项“权限”页验证。

## 8. 配置完成后在哪里看到变化

工作模型本身不会直接影响成员正在使用的版本。完整链路是：

1. 保存字段、布局和字段权限。
2. 到“设置 → 流程与权限”校验配置。
3. 处理阻断、兼容和迁移提示。
4. 发布新的不可变版本。

发布后：

- 模板完整且当前用户可查看时，出现在“概览 → 我的工作 → 可用工作项”。
- 新建工作项使用新的 create 布局和字段投影。
- 新创建事项的“事项详情”使用新的 detail 布局。
- 字段权限影响新绑定版本中的隐藏、只读、可写和必填状态。

现有工作项仍保存创建时的 `typeVersionId + configHash`，不会因发布而静默切换到新布局、字段或权限。需要迁移时必须走显式迁移或 backfill 流程。

## 9. 工作模型完成检查

对每个任务模板逐项确认：

- 模板名称、永久 key、说明和状态正确。
- 业务字段齐全，没有用普通文本代替应有的日期/用户/选项类型。
- 选项 key 稳定，废弃选项已停用而非删除。
- create 和 detail 布局都存在。
- 所有布局字段仍为 active。
- 关系节点引用现有 relation key。
- owner/admin/member/guest 字段权限符合预期。
- 访问预览已使用保存后的策略运行。
- 接下来会到“流程与权限”校验并发布。
