# 主 Tab：设置

“设置”属于空间管理区，当前只对 owner/admin 显示。它不是一个杂项页面，而是按照“了解状态 → 建模 → 发布 → 自动化 → 度量 → 生命周期”的顺序集中管理空间。

设置共 6 个子 Tab，顺序如下：

1. 管理首页
2. 工作模型
3. 流程与权限
4. 自动化与协同
5. 度量治理
6. 场景模板

“A. 基础信息”直接位于管理首页中，空间停用、归档和恢复操作也收拢在该卡片的保存区，不再占用独立子 Tab 或独立危险操作卡。本章说明管理首页及其中的基础信息；后续设置项因内容较多，各自单独成章。

设置在 active、disabled、archived 空间中都可进入；后两种状态应按只读理解，最终写入仍由服务端校验。

## 1. 管理首页

管理首页是管理员进入设置后的总览、快捷入口和基础信息编辑入口。“A. 基础信息”可直接修改空间名称、可见性和说明；页面不再重复展示空间名称、可见性和当前状态的汇总卡。

### 1.1 空间管理提示

显示当前使用简洁还是高级模式。两种模式只改变说明密度，不改变权限，也不会隐藏已经授权的入口。

### 1.2 克隆配置预检

只有本次会话是通过“参考其他空间创建”进入时显示。

它明确提醒：创建空间时没有复制成员、工作项或配置，只保留参考空间名称。管理员必须进入“工作模型”逐项核对，并主动完成校验和发布。

### 1.3 配置健康

显示三个数字：

| 指标 | 含义 |
| --- | --- |
| 可用任务模板 | active 且拥有完整可运行配置的模板数 |
| 待发布配置 | active 但配置尚未就绪的模板数 |
| 空间成员 | 当前成员总数 |

“可用任务模板”不是模板总数；只有完成发布且运行时就绪的模板才计入。

### 1.4 配置待办

最多列出前 5 个待发布任务模板。点击一项会进入：

```text
设置 → 流程与权限 → 对应任务模板
```

如果模板没有出现在成员“概览 → 可用工作项”，这里是优先排查入口。

### 1.5 最近入口

记录当前管理员最近访问的最多 4 个设置页。

这是当前工作区、账号、空间下的 `sessionStorage` 便捷记录，不是服务端审计事实，不跨浏览器同步，也不应作为变更证据。

### 1.6 全部管理入口

快捷进入：

- 工作模型
- 流程与权限
- 自动化与协同
- 度量治理
- 场景模板
- 成员与邀请

## 2. A. 基础信息

管理首页中的“A. 基础信息”卡直接修改空间自身的展示信息和发现范围，并在同一操作区提供空间生命周期动作。

### 2.1 空间名称

- 必填。
- 保存前去除首尾空格。
- 最长 128 个字符。

### 2.2 可见性

| 值 | 含义 |
| --- | --- |
| `private` | 仅空间成员可见 |
| `workspace` | 企业内其他用户可以发现空间元数据 |

“企业内可发现”不授予工作项、成员或项目内容权限，也不自动让发现者成为成员。

### 2.3 空间说明

- 可选。
- 最长 2,000 个字符。

建议写明目标、范围、参与团队、数据敏感性和不在本空间处理的内容。

### 2.4 保存设置与生命周期动作

- 只有 active 空间可以保存。
- disabled、archived 时按钮不可用。
- 服务端再次校验 owner/admin 身份。

保存后，名称、说明、可见性会反映在公共头部和空间列表；可见性变化只影响发现范围，不重写已有成员和工作项权限。

生命周期按钮位于“保存设置”右侧，并只按服务端返回的 `availableActions` 显示：active 空间通常提供“停用”和“归档”，disabled 空间提供“恢复”和“归档”，archived 空间提供“恢复”。停用和归档使用危险样式并要求二次确认；恢复沿用同一位置，不需要进入其他设置页。
