# 主 Tab：概览

“概览”是成员进入空间后的个人工作入口，不是项目整体统计看板。它回答三个问题：

1. 目前哪些事项和我有关？
2. 当前有哪些已经发布、我可以使用的任务模板？
3. 最近有哪些与我相关的事项变化？

概览中的内容会经过工作项查看权限、参与角色、节点任务、配置发布状态和空间状态过滤。

子 Tab 顺序：

1. 我的工作
2. 动态与边界

## 1. 我的工作

此页包含“我的工作”和“可用工作项”两张卡片。

### 1.1 我的工作卡片

系统最多读取当前空间内 12 条个人相关事项，并按下列顺序分桶：

| 分桶 | 进入条件 |
| --- | --- |
| 待我处理 | 当前用户存在待处理的节点流程任务 |
| 我负责的 | 当前用户是事项的 owner 或 assignee |
| 我参与的 | 当前用户是事项的 collaborator |
| 我关注的 | 当前用户是事项的 watcher |

同一个事项可以同时出现在多个分桶中。每个桶显示可见数量和最多 3 条事项；每条显示标题、事项编号、任务模板名称和“打开”入口。

只有服务端明确允许 `view` 的事项才会出现。结果超过当前预算时显示“还有更多事项”，但当前页面没有加载更多入口。

空状态和错误状态：

- 单个分桶为空：显示“当前没有事项”。
- 四个分桶都为空：显示“当前没有需要你处理、参与或关注的事项”。
- 有工作项入口时可点击“浏览团队工作项”。
- 加载失败时显示“我的工作加载失败”，可重试。
- 归档空间通常不会再进入个人工作候选集合，因此结果可能为空。

### 1.2 可用工作项卡片

这里只展示同时满足以下条件的任务模板：

1. 配置已经发布且可运行，即 `configurationReady=true`。
2. 当前用户拥有该模板的 `view` 动作。

每个模板显示名称和当前可执行动作：

- 空间为 active 且模板允许 `create`：显示“可创建新事项”。
- 其他情况：显示“查看已有事项”。

点击后的结果：

- 可创建：进入“工作项”，预选该模板并打开新建窗口。
- 只可查看：进入“工作项”并筛选该模板。

如果这里没有期望的模板，按以下顺序检查：

1. “设置 → 工作模型”中模板是否启用。
2. 字段与 create/detail 布局是否已经保存。
3. “设置 → 流程与权限”中的草稿是否校验通过并发布。
4. 当前用户是否有该模板的 `view`，以及 active 空间中的 `create` 权限。

配置关系如下：

```text
工作模型：任务模板 + 字段 + 页面布局
                    ↓
流程与权限：校验并发布不可变版本
                    ↓
概览：可用工作项
                    ↓
工作项：新建窗口和事项详情
```

## 2. 动态与边界

“动态与边界”在同一个页面中依次展示“空间动态”和“协作边界”两张卡片。

### 2.1 空间动态

“空间动态”显示最近最多 12 条与当前用户可见个人事项有关的活动。每条包含事项标题、事项编号、活动名称、时间，并可打开对应事项。

当前可读活动名称包括：

- 已创建
- 已更新
- 状态已变化
- 有新协作记录
- 新增参与人
- 参与人已调整
- 已归档
- 未识别类型统一显示“事项有新变化”

页面状态：

- 加载失败：显示“空间动态加载失败”，可重试。
- 没有动态：显示“还没有与你相关的空间动态”。

需要注意：

- 这里不是整个空间的完整审计日志，只包含个人工作范围内的可见事项。
- 接口虽然返回未读数、截断信息和下一页游标，当前页面尚未显示未读数，也没有标记已读或加载更多。

### 2.2 协作边界

此页显示三个空间级事实：

- 当前角色
- 内容可见性
- 空间状态

它用于提醒用户当前的协作边界：项目空间是团队成员的日常协作入口；企业治理、全局风险和全局审计检索属于企业管理后台。

这里不解释某一条事项的具体权限。要了解对某个事项可查看、编辑或流转哪些内容，请进入“工作项详情 → 权限”。

## 3. 非成员看到的概览

当空间可被工作区发现但当前用户不是成员时，不会加载“我的工作”“空间动态”和“协作边界”的成员内容，只显示最小空间元数据：

- 空间说明
- 可见性
- 空间状态
- 必须加入空间后才能查看工作项、成员和项目内容的提示

可发现不等于可读取内容，也不等于获得成员身份。

## 4. 成员的日常使用顺序

1. 进入“我的工作”，先处理“待我处理”。
2. 查看“我负责的”和“我参与的”，确认近期协作事项。
3. 需要新建事项时，从“可用工作项”选择模板。
4. 进入“动态与边界”，通过“空间动态”了解最近变化。
5. 在同一页查看“协作边界”；仍有权限疑问时，再进入具体事项的“权限”。
