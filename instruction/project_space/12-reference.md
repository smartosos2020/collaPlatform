## 2. 相近概念对照

| 容易混淆的概念 | 区别 |
| --- | --- |
| 任务模板 / 工作项类型 | 同一个定义对象；前者是用户文案，后者常见于代码和旧文案 |
| 工作项 / 事项 | 同一个运行对象 |
| 工作模型 / 已发布配置 | 工作模型是编辑入口；只有发布版本才供运行时使用 |
| 配置模板 / 场景模板 | 前者复用一个任务模板完整配置；后者描述多个跨模块组件 |
| 状态流程 / 节点流程 | 前者单状态机；后者支持任务、审批、分支、汇聚、交付物 |
| 项目计划阶段 / 流程节点 | 计划用于项目时间和里程碑；流程节点用于事项运行，不自动同步 |
| 数据权限 / 字段权限 | 数据权限先决定能否访问事项和动作；字段权限再决定字段 hidden/read/write |
| 空间角色 / 事项角色 | 空间角色决定空间层治理；事项角色描述人与某条事项的关系 |
| 风险与决策 / 指标风险 | 前者是人工台账；后者由已发布策略从事实派生信号 |
| 结果指标 / 看板配置 | 当前复用同一组件；项目管理入口偏消费，设置入口偏配置 |
| 项目管理跨空间同步 / 设置跨空间同步 | 当前是同一组件、同一规则和运行数据 |
| 停用模板 / 退役模板 | 停用可恢复；退役不可恢复 |
| 停用空间 / 归档空间 | 停用是暂停协作；归档是历史封存，当前部分页面无法读取归档数据 |

## 3. 关键状态

### 3.1 空间

- active：正常协作。
- disabled：数据保留，写入和成员治理关闭。
- archived：历史只读；部分服务当前会拒绝读取。

### 3.2 任务模板和字段

- active：参与配置和运行时判断。
- disabled：暂时不供成员使用，可恢复。
- retired：退役，不可恢复。

### 3.3 配置草稿

- editing
- validating
- valid
- invalid/blocked
- abandoned

### 3.4 发布兼容性

- compatible：可直接发布。
- review_required：需要人工复核。
- migration_required：需要明确迁移方案。
- blocked：禁止发布，没有普通绕过。

### 3.5 风险信号

- open
- acknowledged
- suppressed
- closed
- invalidated

### 3.6 不完整结果

- unknown：当前事实不足以判断。
- suppressed：安全或最小样本规则抑制。
- stale：超过新鲜度要求。
- truncated：预算内部分结果。
- no_sample：没有可计算样本。

任何一种都不等于 0。

## 4. 身份与权限层次

```text
企业身份与账号状态
        ↓
空间成员关系与空间角色
        ↓
主导航 availableActions
        ↓
任务模板发布状态和模板动作
        ↓
事项数据权限策略
        ↓
事项角色、流程守卫、当前状态
        ↓
字段访问投影
        ↓
服务端最终命令校验
```

前端按钮显示不是最终授权。部分当前组件使用较粗的 `edit` 或角色名显示按钮，点击后仍可能由服务端拒绝。

## 5. 永久 key、UUID、版本和哈希

- 永久 key：面向配置版本和差异的稳定语义标识，创建后不应随意改变。
- UUID：对象实例标识。当前多个高级页面仍要求手工输入，应复制完整值并核对空间。
- aggregate version：用于乐观并发控制，避免覆盖其他人的修改。
- immutable version：已发布后不原地改写的版本。
- config/definition/manifest hash：当前内容的确定性指纹，用于判断差异和重放。

当服务端提示版本冲突时，应刷新、比较并重做操作，不要盲目重复提交旧版本。

## 6. 当前版本最需要注意的边界

### 导航与归档

- 普通 member/guest 只看到概览和工作项。
- 项目管理底层有些 member 能力当前没有导航入口。
- archived 名义只读，但多个项目管理服务会返回不可用。

### 工作项集合

- “全部类型”当前实际回退到第一个模板。
- 单次最多 50 条，没有加载更多。
- 自定义字段不能加入集合列。

### 工作模型运行时

- 用户、附件、工作项引用字段控件未完整接线。
- 布局显示条件当前不执行。
- relation/summary 布局节点当前主要为占位展示。

### 流程与权限

- 权限编辑器只编辑第一个 Subject，多种高级 data scope 有接线差异。
- 节点流未保存不会锁住顶层发布，必须单独保存。
- 发布不会迁移已有工作项。

### 项目管理

- 计划的阶段、里程碑和工作项关联缺少完整 UI。
- 多个资源页面要求手输 UUID。
- 交付版本的真实物料和拒绝闭环未完整接线。

### 成员

- Web 端没有邀请收件人的接受/拒绝页面。
- member/guest 没有可见退出空间入口。

### 自动化和跨空间

- 可视化规则只编辑一个条件和动作。
- 连接器缺少编辑、停用、删除、死信重放。
- 跨空间对象缺少选择器，同步只支持一个字段复制映射。

### 度量和场景

- ratio 指标缺少分子/分母输入。
- 看板只支持单数据源、单图表、固定布局。
- 治理导出当前只返回回执，不直接下载文件。
- 场景安装目前只真实创建任务模板，其他组件需逐块配置。

## 7. 文档版本边界

本手册以代码提交 `0822e945ddc0` 和 2026-08-01 的工作区实现为基线。它描述当前可见行为，不把路线图目标或场景清单中的计划能力写成已经完整接线的功能。

界面或服务端发生以下变化后，应重新核对相应章节：

- 主/子 Tab 顺序或角色能力改变。
- 配置快照 schema 改变。
- 字段或布局运行时接线补齐。
- 权限策略校验/运行时语义变化。
- 项目管理、邀请、跨空间或场景安装闭环补齐。
