# Colla Platform

Colla Platform 是面向研发团队及跨职能团队的一体化协作平台。它把项目推进、工作项管理、即时沟通、知识沉淀、结构化数据、审批和企业治理放在统一工作空间中，帮助团队减少信息分散，让目标、责任、过程和结果保持一致。

## 产品愿景

让团队在一个清晰、可配置、可治理的协作空间中完成从需求提出、计划执行、过程沟通到结果复盘的完整闭环。

平台重点解决以下业务问题：

- 项目、任务、消息、文档和数据分散，信息难以关联。
- 不同团队工作方式不同，固定流程难以适配实际业务。
- 责任人、状态、依赖和审批边界不清，推进过程缺少透明度。
- 知识沉淀与日常执行脱节，经验难以复用。
- 管理者缺少统一的进度、风险、资源和效能视图。
- 企业权限、内容访问和操作记录缺少一致的治理边界。

## 服务对象

| 用户 | 主要诉求 |
| --- | --- |
| 一线成员 | 查看我的工作、处理待办、更新进度、参与讨论和沉淀知识 |
| 项目负责人 | 规划工作、分配责任、管理依赖、识别风险并推动交付 |
| 空间管理员 | 配置团队工作方式、成员角色、流程、权限和业务模板 |
| 部门与企业管理者 | 查看跨团队进展、资源与效能，治理组织、权限和风险 |
| 企业管理员 | 管理成员、部门、用户组、角色、安全、应用和审计记录 |

## 核心业务能力

### 个人工作台

- 聚合待我处理、我负责、我参与和我关注的工作。
- 汇总消息、通知、审批待办和最近访问内容。
- 根据用户身份展示可进入的项目空间和可执行动作。
- 通过统一搜索快速定位工作项、知识内容、表格数据和消息。

### 项目空间

项目空间是团队、工作规则、权限和协作内容的业务边界。每个空间可以根据团队实际工作方式进行配置，并保持成员执行区与管理配置区相互独立。

主要能力包括：

- 创建和管理项目、需求、任务、缺陷、迭代、版本等工作项。
- 自定义工作项类型、字段、表单和详情页面。
- 配置状态流、审批流、协作节点和负责人规则。
- 建立父子层级、关联、依赖和跨空间协作关系。
- 按角色、参与关系、字段和数据范围控制访问与操作权限。
- 使用表格、紧凑列表、层级树、看板、日历和甘特视图组织工作。
- 管理估算、工时、人员分配、资源产能和团队排期。
- 通过自动化规则完成提醒、状态联动、通知和外部协作。
- 通过指标、看板和风险规则观察进度、质量、效率和交付结果。
- 将成熟的工作模型保存为模板，在不同团队和空间中复用。

### 即时沟通

- 支持单聊、群聊和项目会话。
- 支持消息回复、编辑、撤回、置顶、表情和已读状态。
- 可从消息直接创建工作项，并保留消息与事项之间的业务关系。
- 内部链接可展示为业务对象卡片，帮助成员理解上下文。
- 会话内可搜索消息并定位到具体讨论位置。

### 知识库

- 以知识空间和目录组织团队规范、方案、经验与业务资料。
- 支持结构化内容、评论、版本、分享和协同编辑。
- 支持将工作项、表格和其他业务对象作为知识目录入口或内容引用。
- 阅读者默认进入内容，权限与治理信息作为辅助入口。
- 知识内容与被引用对象分别遵守各自的访问权限。

### 多维表格

- 使用数据表、字段、记录和多种视图管理结构化业务信息。
- 支持筛选、排序、字段显隐、看板、日历、评论和关联对象。
- 适合需求池、资产台账、风险清单、客户反馈、内容计划等场景。
- 可被知识库引用，同时保持数据归属和权限独立。

### 审批

- 支持发起、处理、拒绝、转交和撤回审批。
- 聚合个人审批待办和处理记录。
- 审批结果可以与项目执行、通知和业务对象形成协作闭环。

### 通知与搜索

- 统一接收事项变化、协作提醒、审批结果和系统通知。
- 支持按状态、来源和业务对象筛选通知。
- 搜索结果遵循当前用户权限，不展示无权访问的业务内容。
- 从搜索结果和通知可直接回到对应业务上下文。

### 企业管理与治理

- 管理企业成员、部门层级、部门负责人和成员归属。
- 使用用户组维护跨部门、跨项目的成员集合。
- 配置角色与权限，识别高风险授权和异常访问关系。
- 治理项目空间、知识库、应用和业务内容的生命周期。
- 记录登录、成员、组织、权限及业务对象变更，支持审计追溯。
- 企业治理权限不会自动转化为私有协作内容的访问权限。

## 典型业务场景

### 研发与产品交付

管理产品需求、研发任务、缺陷、迭代和版本；连接需求评审、开发、测试、发布与复盘过程。

### 市场与内容协作

管理活动计划、内容生产、素材准备、渠道执行、审批和效果复盘，并通过日历和看板协调节奏。

### 客户与项目交付

跟踪交付计划、里程碑、责任人、风险、问题、验收项和客户反馈，形成可追溯的交付记录。

### 人事与内部运营

组织招聘、入职、培训、制度审批和内部服务事项，同时通过知识库沉淀标准流程与常见问题。

### 团队知识管理

将制度、方案、复盘、操作手册与真实业务对象连接，让知识能够被发现、引用和持续更新。

## 产品边界

- 用户工作区服务日常执行与内容协作；管理后台服务组织、权限、安全和审计治理。
- 组织角色、空间角色、工作项角色和流程负责人属于不同业务层级，不互相替代。
- 项目空间定义团队的协作边界，企业管理员不会因治理身份自动获得空间内容权限。
- 知识库负责组织和呈现知识，不复制被引用表格或其他业务对象的数据。
- 停用或归档用于控制业务生命周期，重要内容和操作记录仍保持可追溯。
- 平台强调可配置协作与统一治理，不替代财务、ERP、专业 CRM 或专业人力资源系统。

## 当前方向

Colla Platform 当前以项目空间为核心业务主线，并持续完善角色化工作区、低门槛配置、跨团队协作和真实团队使用体验。产品目标不是堆叠功能，而是让成员更容易找到当前工作，让负责人更容易推动结果，让管理员在不干扰日常协作的前提下完成治理。
