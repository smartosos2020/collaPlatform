# PROJECT-PLATFORM-S21-M4 项目空间信息架构审计与冻结合同

## 1. 审计结论

当前项目空间已经具备 S02-S20 的完整能力，但用户侧仍按能力建设顺序组织：

- 一级入口为协作概览、工作项、工作项类型、页面布局、成员、空间设置。
- 项目计划、资源、交付和自动化连续放在工作项内容下。
- 跨空间、场景模板、指标定义和治理连续放在概览内容下。
- 类型、字段、布局和配置发布分别占用路由与面板。
- owner/admin 显隐主要依赖角色名，服务端 `availableActions` 尚未成为统一导航输入。

revision 50 冻结目标为五个按任务组织、按能力动态出现的一级入口：

1. 概览
2. 工作项
3. 项目管理
4. 成员
5. 设置

M4 只冻结信息架构、术语、角色、路由和可访问性合同；M5 才把现有页面接入新 Shell，不在 M4 删除旧路由或改写 owner 事实。

## 4. 内容层与高级配置

| 内容层 | 内容 | 默认呈现 |
| --- | --- | --- |
| 高频执行 | 概览、工作项、动态、关系与协作记录 | 简洁模式直接可达 |

- 工作模型：任务模板、字段、表单与页面、发布配置。

- 自动化与协同：规则、运行记录、连接器、跨空间授权和同步。
- 度量治理：指标定义、看板配置、风险策略和治理报表。
- 场景模板：研发、市场、HR、交付模板安装、差异和升级。

## 6. 简洁/高级模式合同

- 默认：所有用户进入简洁模式。
- 可切换身份：仅当前有 `view_settings` capability 的空间身份；不按 owner/admin 名称判断。
- 作用域：用户 + workspace + space；不能跨空间复用权限或配置快照。
- 离线：读取失败回到简洁默认；不能显示上次高级模式中的陈旧成功或隐藏内容。
- 回退：偏好或新 Shell 失败时保留旧配置深链和业务事实，不恢复 legacy project/issue 产品入口。
- 授权：模式、偏好、缓存、feature flag、realtime 和遥测都不授权。

## 8. 上下文与可访问性

- 从执行页进入设置时记录原路由和 query，完成或取消后可返回原任务。
- 兼容深链显示“设置 / 高级配置 / 当前组”的上下文，不把旧路径错误标为新的一级入口。
- 1440 和 1366 使用单行一级导航；820 使用可横向操作的导航和可折叠空间列表。
- 键盘焦点顺序为页面标题、空间状态、一级导航、二级导航、当前内容和操作。
- 当前入口使用 `aria-current` 或等价语义；长名称截断必须保留完整可访问名称。
- 隐藏入口不得挂载和预取其私有数据；CSS 隐藏不能作为权限实现。

## 9. 四场景静态走查与威胁模型

| 场景 | 简洁路径 | 必要高级路径 | 走查结论 |
| --- | --- | --- | --- |
| 研发 | 概览 -> 工作项 -> 项目管理 | 工作模型、流程与权限 | 需求/任务/缺陷与计划分层清楚 |
| 市场 | 概览 -> 工作项 -> 项目管理 | 场景模板、自动化与协同 | 活动执行与模板/渠道配置分离 |
| HR | 概览 -> 工作项 -> 项目管理 | 工作模型、流程与权限 | 候选人敏感字段仍由 owner 权限控制 |
| 交付 | 概览 -> 工作项 -> 项目管理 | 场景模板、度量治理 | 交付执行、验收与治理指标分离 |

阻断威胁及 M5/M7 控制：

- 直接 URL 绕过导航：每次 API 仍执行服务端授权，导航不授权。
- CSS 隐藏后仍预取：M5 按可见导航懒加载，M7 检查网络和错误外形。
- enterprise-admin 旁路：非成员保持治理 Shell，仅返回治理元数据。
- 模式偏好保存权限：偏好只保存枚举和版本，不保存 role/capability。
- 旧深链重定向泄漏：保留原路径和 query；无权返回统一拒绝外形。
- 归档/停用空间陈旧写：只读状态覆盖 Shell，mutation 仍由 owner API 失败关闭。

## 10. M5 准入结论

Go `PROJECT-PLATFORM-S21-M5`，前提是：

- 只用上述集中合同构建一级导航和 route context。
- 保留现有二级 Tab 基底和受支持深链，不覆盖既有未提交实现。
- 项目管理与高级设置只组合现有 owner 公共组件，不复制业务事实。
- 模式偏好由后端持久化并失败回到简洁默认。
- 六身份、三视口、键盘、深链、离线和多标签在 M5 独立工作循环验证。
